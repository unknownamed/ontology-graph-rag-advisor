# 하나의 채팅방 UI와 페이지 상태

## 현재 화면

`web/index.html`의 기존 HTML/CSS/JavaScript와 서버 정적 페이지 경로를 사용한다. 새 프레임워크나 서버 대화 저장소는 없다. 상단은 제목·실제 적용 학생 상태·설정, 중앙은 시간순 대화·파일 카드, 하단은 첨부·여러 줄 질문·전송이다. StudentState JSON과 로컬 LLM 설정은 **학생 정보 · 설정**에 있다.

과목·정책 질문은 자료 없이 허용한다. 개인 질문은 현재 명시적으로 적용한 StudentState만 서버에 전달한다. 파일 선택과 후보 추출은 기존 학생 상태를 변경하지 않는다.

## 상태 소유권

| 상태 | 보관·변경 규칙 |
| --- | --- |
| 현재 대화 | 페이지 DOM의 메시지. 파일 선택·추출·학생 교체로 지우지 않는다. |
| 적용 학생 상태 | `ChatSession.applied`의 복사본. 업로드 정규화 또는 JSON을 명시적으로 적용할 때 교체한다. 합치지 않는다. |
| 검토 중인 업로드 | `pending`에 선택 파일·추출 후보·정정값·정규화 후보를 보관한다. 적용 상태와 분리한다. |
| 질문 context | 기존 API의 제한적인 마지막 과목 참조 등. 학생 교체·비우기·전체 초기화 시 무효화한다. |
| 요청·과거 답변 | 전송 당시 학생/context 복사본과 반환 payload를 고정한다. 과거 근거를 현재 학생으로 다시 계산하지 않는다. |

학생 업로드의 확인·미확인·원문 값은 기존 정규화 계약을 그대로 사용한다. 파일을 선택했다고 분석 완료로 표시하거나 적용 교육과정·전체 이수범위·졸업 증빙을 VERIFIED로 승격하지 않는다.

## 파일과 초기화

첨부 → 파일 카드 → 후보 추출 → 검토 패널의 원문/연결/정정 확인 → 정규화 결과 생성 → **학생 이수정보로 적용** 순서다. 새 파일은 기존 pending 후보를 폐기하지만 대화와 적용 학생은 유지한다. 정정하면 정규화 후보를 무효화한다. 재추출·재정규화 중에는 이전 후보를 적용하지 못한다.

| 조작 | 지우거나 바꾸는 범위 |
| --- | --- |
| 패널 열기·닫기 | 대화·질문 초안·적용 학생·정정값을 유지한다. |
| 선택 파일 폐기 / 검토 업로드 폐기 | pending 파일·후보·정규화 후보만 제거한다. 파일 카드는 검토 종료 기록으로 남긴다. |
| 새 학생 적용 | 확인 후 현재 학생을 교체하고 context를 초기화한다. 이전 답변은 보존한다. |
| 적용 학생 정보 비우기 | 범위 확인 후 적용 학생과 context만 지운다. 대화·pending·질문 초안은 유지한다. |
| 전체 초기화 | 범위 확인 후 이 탭의 대화·학생·파일 후보·context·질문 초안을 지운다. 공식 규칙과 자료에는 쓰지 않는다. |
| 새로고침 / 새 탭 | 빈 상태로 시작한다. 자동 복원·영구 저장·다른 탭 동기화는 없다. |

## 비동기와 입력

학생 revision·요청 serial·업로드 generation·정정 revision을 대조한다. 학생 변경 시 이전 질문을 취소하고 늦은 응답을 버린다. 파일 교체·폐기·재추출 후 이전 업로드 응답도 버린다. 정규화 도중 정정한 경우 이전 결과를 적용하지 않는다.

응답 중 전송을 막고 실제 대기만 표시한다. Enter는 전송, Shift+Enter는 줄바꿈이며 `isComposing`, composition 이벤트, keyCode 229 동안 전송하지 않는다. 이전 메시지를 읽는 위치를 유지하고 **새 메시지 ↓**로 이동할 수 있다.

## 답변과 근거

서버의 `answer_text`와 결정값을 유지한다. 근거는 답변 당시 학생 → 실제 관계/그래프 → Rule·계산 → PDF → 문서집합·RuleSet·질문 해석·전체 JSON 순서다. 그래프는 실제 반환 관계의 부분집합이며 최대 12개 후보 연결을 표시한다. 전체 관계는 EvidenceBundle로 접근 가능하다. 전체 후보는 요청 시 펼쳐지고 필수/선택을 구분한다. 노드 방문 순서·수강 우선순위·실제 개설 정보를 만들지 않는다.

검수는 [2026-10-01 UI 보고서](../../evaluation/results/chat_ui_acceptance_2026-10-01.md)에 기록한다. 실제 OS 한글 IME와 모바일 기기의 가상 키보드 실기기 검수는 자동 브라우저/이벤트 단위 검수와 구분한다.
