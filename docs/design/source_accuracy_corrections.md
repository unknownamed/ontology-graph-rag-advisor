### 영어 면제의 조건 결합

- 비면제 일반 학생의 기초교양 기준 **9학점**은 유지한다.
- 공식 영어 면제 결과 `VERIFIED`, 확인 입력의 `evidence_id`, 실제 영어 이수 여부를 검사한다. 시험점수 충족만으로 개인 면제 완료를 만들지 않는다.
- 영어를 이수하지 않고 면제가 확인된 경우만 해당 기초교양 Rule의 요구값을 **9→7**로 조정한다. 미래설계1·AI기초3·글쓰기3의 독립 지정 조건은 그대로다.
- 면제로 학점을 부여하지 않는다. 교양 총34, 균형12·영역 조건 및 졸업 산입 상한42를 그대로 실행한다. 다른 교양의 실제 이수 학점이 보충량을 채운다.
- 보충이2 부족한 fixture는 교양32·총128로 미충족, 면제가 미확인이면 영어 및 기초 조건을 확인 필요로 반환한다.
- 후보 계산은 같은 RequirementResult를 사용한다. 면제 영어를 REQUIRED로 만들지 않으며, 보충 가능한 다른 교양을 ELIGIBLE_OPTION으로 남긴다. 개설·수강 가능성은 보장하지 않는다.
- 학생 상태 없는 시험기준 조회를 허용한다. 대학영어 면제 TOEIC700과 졸업인증의 영어 기준을 합치지 않는다.

### 적용연도와 질문 범위

문서연도, 입학연도, 학점기준 연도, 과목표 연도와 RuleSet 버전은 독립 값이다. 질문의 `year_targets[]`는 `ADMISSION_YEAR`, `CREDIT_POLICY_YEAR`, `CATALOG_YEAR`, `DOCUMENT_YEAR`를 구분한다. 입학연도로 질문하지 않았다면 정책 조회의 `entry_year`를 임의 생성하지 않는다.

`2022학번`, `2022 교육과정 적용자`, `2022년도 기준`, `2021~2024 적용자`, 복수 연도 비교를 각각 구조화한다. 비교 대상마다 허용 조회와 `POLICY_YEAR_RESULT`가 남는다. 지원하지 않는 연도·과목표·문서는 확인 필요로 반환하며2026 수치로 대체하지 않는다. 질문과 학생 상태의 연도가 다르면 현재 학생 상태의 계산을 **부분 결과**로 표시하고 질문의 다른 연도 졸업판정은 확정하지 않는다.

13쪽의 입학 당시 학점기준/개편 이수교과목 원칙, 264쪽 경과조치와 기존 연도별 학점표는 정책 설명에 사용한다. 과거 과목표 전체와 개인별 예외 RuleSet을 복원했다고 설명하지 않는다.

### coverage와 입력 경계

`coverage_complete`는 현재 등록된 Core RuleSet, 확인된 적용조건, 필요한 학생 입력을 기준으로 실행 경계가 충족됐는지 나타낸다. PDF 전체의 모든 세부 절을 직접 계산했다는 뜻이 아니다. `coverage_details`와 실제 `COVERAGE_CHECK`를 함께 사용한다.

- 적재 Rule 실행 여부 / 적용조건 식별 여부 / 미검증 Rule / 미처리 조건 / 필수 입력 확인 여부를 분리한다.
- 직접 계산 Rule, 확인된 공식 최종 결과를 사용한 Rule, 원문상 면제 Rule을 각각 기록한다.
- 명시된 초과학제·재입학·전과 및 미지원 면제/동일·대체 주장 등 관련 조건을 조용히 버리지 않는다. 관련 없는 학년 라벨·별명 때문에 정상 판정을 보류하지 않는다.
- 장애학생 인증 면제는 569쪽 원문과 확인된 조건 입력을 연결해 NOT_APPLICABLE로 처리한다. 미확인 장애 주장만으로 면제하지 않는다. 별도로 확인된 인증 통과 결과가 있으면 장애 입력 불확실성이 그 통과 결과를 무효화하지 않는다.
- 논문 합격/신청 및 인증 통과는 확인 입력을 사용한다. 인증 세부 시험·자격 전체 계산은 **`certification_subrules_computed:false`**다. 화면도 이 구분을 표시한다.
- 이수내역 완전성·적용조건·공식 결과 확인 입력은 판정 입력의 신뢰 경계다. 학교가 모든 학생에게 새 확인서를 제출하라고 요구한다는 뜻이 아니다. 동일·대체 지정이 실제 인정에 필요한 경우의 확인은 유지한다.
- 확인된 미충족과 관련 조건의 NEEDS_INFORMATION은 동시에 표시한다. 가상의 외부 규정을 새 보류 사유로 만들지 않는다.
