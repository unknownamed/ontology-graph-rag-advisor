# 컴퓨터공학과 졸업·이수 판정 원문 범위

## 기준과 판독 상태

- 유일한 사실 기준은 `docs/curriculum/2026년도 교육과정.pdf`(615쪽, SHA-256 `0d800318dc367a89518f9be6be8f559092474bf00b3573e14bd37b6c44b54471`)다. 아래 페이지는 PDF의 물리적 페이지이며 인쇄 페이지는 8쪽 작다.
- 학과 공식 명칭은 **컴퓨터공학과**(PDF 259의 장 제목)다. 이 문서의 학점표·43개 전공 과목 행·`※`·경과조치와 졸업 별도 조건은 추출 텍스트를 원문 렌더링과 대조했다. 과목표는 **2026학년도 편성표**이며 이전 적용연도의 필수과목 목록을 자동으로 대체한다고 해석하지 않는다.
- `VERIFIED`는 원문 페이지를 육안 대조한 값, `UNVERIFIED`는 이 PDF나 현재 확인 범위로 확정하지 못한 항목이다. 이 문서는 판정 결과나 학생별 인정학점을 제공하지 않는다.

## 구현 중 확인한 교양 원문 충돌

PDF 42(인쇄 34)의 균형교양 `GEA8617 수식없는물리로보는세상` **2학점**과 PDF 45(인쇄 37)의 확대교양 `GEA8617 융합프로젝트Ⅰ` 3학점은 **같은 학수번호에 서로 다른 과목명·영역·학점**으로 표기되어 있다. 자동 추출은 42쪽을 3학점으로 잘못 읽었으며, 두 원문 페이지를 렌더링해 수치를 바로잡았다. 공식 정정 또는 학생의 실제 과목 식별 근거가 없으므로 코드만으로 자동 분류·인정하지 않는다(`CONFLICTED`). 34–45쪽의 나머지 중복 없는 교양 280행은 페이지 이미지와 코드·과목명·학점·영역을 대조해 출처 연결 상태로 적재했다.

## 판정 입력과 미확인 경계

- 학점·잔여·영역 질문에는 **입학연도, 실제 교육과정 적용연도, 학적 변동(편입/전과/재입학), 이수유형, 과목별 이수코드·학기·학점·성적·인정구분, 재수강/동일/대체 지정과 학생 선택, 외부/교류 학점 인정 결과**가 필요하다. PDF의 과목 편성 사실은 학생이 이수했다는 증거가 아니다.
- 필수 과목 질문에는 적용연도별 필수과목과 개편 후 과목 사이의 공식 동일·대체 지정이 필요하다. **이 PDF에서 해당 지정 목록을 확인하지 못했다(`UNVERIFIED`)**. 2026 편성표를 2002–2025 입학생의 과거 필수 목록으로 소급하지 않는다.
- 졸업 가능 질문에는 학점 외에 논문 심사·최종학기 신청, 졸업인증 적용/면제·증빙, 다전공 선발·포기 및 제2전공 요건이 필요하다. PDF 567의 학과 논문 대체 없음과 PDF 572의 학과 지정 실용인증 자격증 없음은 서로 다른 항목이다.
- 실습과 캡스톤은 전공선택 과목표 등재와 졸업자격인증 인정이 별개다. 산학협력인증은 PDF 575(인쇄 567)의 인정 시점·교과목 구분별 중복 금지·대학정보공시 단서를 별도로 검증해야 한다.
- 아직 확인하지 않은 영역: 과거 교육과정의 개별 과목표, 2002–2005 총 졸업학점·2010–2012 컴퓨터공 복수전공 독립 행, 공식 동일/대체 지정 목록, 학생별 적용연도·전적대/편입 인정·논문/인증 증빙, 외부 운영지침에만 있는 세부 기준. 부족한 정보는 **정보 부족**으로 남기며 임의의 불충족 또는 졸업 가능으로 바꾸지 않는다.
